# Educational Knowledge Database (EKDB)

## Purpose

The Educational Knowledge Database (EKDB) is the authoritative educational repository for the DeeglobalGH platform.

It stores educational metadata independently of the shop catalogue.

The shop catalogue references the EKDB rather than duplicating educational information.
